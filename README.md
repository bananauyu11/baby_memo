# 育児メモ

うんち・しっこの回数、ミルク（ml）・おっぱい（分）の記録を家族で共有するWebアプリです。
1日ごとのミルク合計量・最大量、うんち・しっこの回数、おっぱい合計時間の推移を、月ごと・全期間のグラフで見られます。

- `index.html` … 画面（スマホ向け）
- `api/data.js` … データを読み書きするAPI（Vercel Serverless Function）
- データの保存先 … Upstash Redis（無料プランで十分）

## Vercelへのデプロイ手順

1. **Vercelにリポジトリを取り込む**
   [vercel.com/new](https://vercel.com/new) からこのGitHubリポジトリを選んで「Deploy」。
   Framework Preset は「Other」のままでOK（ビルド設定は不要）。

2. **データベース（Upstash Redis）を追加する**
   Vercelのプロジェクト画面 →「Storage」→「Create Database」→ **Upstash for Redis**（Marketplace）を選んで作成し、このプロジェクトに接続します。
   接続すると環境変数 `KV_REST_API_URL` と `KV_REST_API_TOKEN` が自動で追加されます。
   （Upstashのサイトで直接作った場合は `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` を手で登録してもOK）

3. **家族の合言葉を設定する**
   プロジェクト →「Settings」→「Environment Variables」で
   `APP_PASSWORD` = 家族で決めた合言葉
   を追加します。合言葉を知っている人は誰でも記録を見たり書き換えたりできるので、**推測されにくい長めの言葉**にしてください（日本語も使えます）。

4. **再デプロイする**
   「Deployments」→ 最新のデプロイの「…」→「Redeploy」。環境変数はこの後から有効になります。

5. **家族のスマホで開く**
   発行されたURL（`https://〜.vercel.app`）を開いて合言葉を入力。
   iPhoneはSafariの「共有 → ホーム画面に追加」、Androidはメニューの「ホーム画面に追加」でアプリのように使えます。

## しくみ

- 「うんち+1」「ミルク追加」のように操作ごとにサーバーへ送るので、家族が同時に入力しても相手の記録を消しません。
- 電波がないときの入力は端末に保存され、つながったときに自動で送信されます（画面上部に「未送信 n件」と表示）。
- 開いている間は20秒ごと、またアプリに戻ったときに最新の記録を取り込みます。
- 以前の版（端末内だけに保存）で記録したデータは、「設定 → この端末に残っている以前の記録を共有データに送る」で移せます。
- 「設定」からJSONバックアップ・CSVの書き出しができます。
- 共有データが空の状態で最初に開いたとき、手書きメモから起こした 11/7〜11/16 の記録（`seed.json`）が自動で登録されます。
